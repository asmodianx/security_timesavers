# Project Buddy

A lightweight, browser-based project management companion designed to help security leads, engineers, and technical project managers organize milestones, track actionable tasks, and manage project delivery without spreadsheet fatigue or enterprise software overhead.

Part of the **[security_timesavers](https://github.com/asmodianx/security_timesavers)** utility toolkit.

---

## 📌 Overview

Managing technical security initiatives—such as tooling rollouts, quarterly compliance audits, penetration testing remediation tracks, and policy updates—often doesn't require a heavyweight Jira board or complex enterprise project suite. For individual contributors and small project squads, those platforms often create more administrative overhead than organizational value.

**Project Buddy** (`index.html`) provides a clean, responsive, single-page command center to structure initiatives, track deliverables, establish ownership, and keep tasks moving forward cleanly right in your web browser.

---

## ✨ Features

- **Actionable Task & Milestone Tracking:** Create, organize, and monitor operational deliverables, blockers, and project milestones in real time.
- **Zero Dependencies:** Built with pure vanilla HTML, CSS, and JavaScript. Requires no build systems, Node.js packages, or external CDN links.
- **100% Client-Side & Private:** All project data, internal system names, sensitive timelines, and task notes remain strictly in local browser memory. No data is transmitted to external backends or third-party cloud services.
- **Portable & Offline-Capable:** Completely functional in offline networks, air-gapped lab jump boxes, or restricted corporate laptops where external SaaS project management tools are blocked.
