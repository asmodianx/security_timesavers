WorkLog Tracker

A standalone, offline-capable daily work-log tool for information security professionals. No CDN dependencies. No external calls. All data stays in your browser session.

Built following OWASP secure coding practices: textContent-only DOM writes, input validation, sanitized imports, CSP-compatible, no eval().

O*NET Coverage

15-1212.00 Information Security Analysts 15-1299.05 Information Security Engineers

Task categories are drawn directly from O*NET task lists (updated 2025–2026). General workday tasks (clock-in, meetings, admin, etc.) are included as a separate category for complete daily coverage.

How to Use

  • Click any task in the left panel to open the log entry dialog.
  • Set the time (defaults to now), an optional duration via slider, and notes.
  • Flag tasks needing documentation as 🎫 Needs Ticket for later follow-up.
  • Star (☆) tasks to pin them at the top as favorites.
  • Use Export JSON to save your session; Import JSON to restore it.
  • Click Print Report for an end-of-day summary (print to PDF from your browser).

config.js

Edit config.js in the same folder to pre-load your name, organization, default favorites, custom tasks, and ticket system API settings (stub — not active in v1).

Ticket System (v1 Stub)

The ticket-creation API integration is architected but not enabled in this revision. Flag items as Needs Ticket and they will appear in the print report. Set ticketSystem.enabled = true in config.js when ready to integrate.
