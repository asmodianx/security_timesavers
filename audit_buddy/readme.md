# Audit Buddy

An interactive, browser-based compliance audit tracker and evidence collection companion designed to help security leads, GRC analysts, and system administrators prepare, organize, and monitor control assessments directly in the browser.

Part of the **[security_timesavers](https://github.com/asmodianx/security_timesavers)** utility toolkit.

---

## 📌 Overview

Preparing for external and internal security audits (such as SOC 2, ISO 27001, NIST CSF, PCI-DSS, or regulatory compliance reviews) often turns into an overwhelming administrative scramble. Control evidence requests get scattered across disparate spreadsheets, email threads, and ticketing queues, leading to missed deadlines and untracked findings.

**Audit Buddy** (`index.html`) provides a clean, single-pane command center to catalog audit controls, track artifact gathering workflows, monitor review milestones, and assess audit readiness in real time—without requiring expensive GRC platform licenses or exposing sensitive internal control documentation to third-party cloud tools.
